Models, tools and licenses

No model weights are stored in this repository. The scripts download them from Hugging Face at run time, and each keeps its own license. Licenses below are the ones shown on each model card, or in the package metadata for the installed version, when this page was written.

Models/dinov2/dinov2base.py loads facebook/dinov2-base (Apache-2.0 on its model card, same DINOv2 paper) as a feature backbone. It is not one of the depth models above.
